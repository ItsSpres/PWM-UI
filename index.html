STATUS and GET are read-only. Configuration writes require ECU enable OFF and firmware unlock. Send one command and wait for its reply. Unlock is not authentication.


Connection & configuration guide
Use Bluefy on iPhone, or a browser with Web Bluetooth support. Allow Bluetooth, connect, and keep this page in the foreground. A sleeping phone or lost link never serves as the controller’s safety interlock.
The REYAX service is prefilled below. Writable and notifying characteristics are discovered by their properties. If your module exposes several, select the documented UUIDs explicitly.
To change settings with the ECU disabled: HELLO → UNLOCK token → SET field value → APPLY → SAVE. Wait for SAVED. GET shows active settings; staged changes are not active until APPLY. Source calibration permissions cannot be enabled here.
Sender scales and trip thresholds are system-specific. Values with cal=0 remain unverified and are hidden on the gauges; their raw telemetry remains in the terminal and export.
